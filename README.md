# Dress & Magic ✨

Videojuego infantil de moda y personalización. La jugadora elige un escenario, crea outfits, experimenta con prendas y descubre combinaciones mágicas que desbloquean elementos para su colección.

## Escenarios definitivos
- Pista de hielo
- Parque de juegos
- Cine de estrellas
- Dulce pastelería
- Pista de baile fiesta
- Escenario de concierto

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Estructura
```
Dress-Magic/
├── index.html
├── README.md
├── css/
│   └── styles.css
└── js/
    ├── data.js
    └── app.js
```

## Ejecutar
Abre `index.html` en un navegador o utiliza la extensión **Live Server** de Visual Studio Code.

## Prototipo actual
- Menú principal y selección de escenarios.
- Vestidor con categorías de ropa, zapatos, peinados y accesorios.
- Muñeca SVG frontal con capas de personalización.
- Combinaciones mágicas de prueba.
- Colección guardada en el navegador mediante localStorage.
- Pantalla de outfit terminado.

> Los gráficos actuales son provisionales. Se sustituirán progresivamente por los recursos visuales definitivos del proyecto.
