IMPORTANTE SOBRE LAS CAPAS:
- La muñeca base debe estar separada de la ropa.
- Cada prenda debe exportarse en el mismo lienzo, tamaño y posición que la muñeca.
- Dejar transparentes las zonas que no forman parte de la prenda.
- No cambiar el tamaño del lienzo entre prendas: así coinciden al superponerse.
- Si el dibujo original actualmente tiene ropa que se debe quitar, primero hay que preparar una versión base de la muñeca sin esa ropa.
- Los nombres de archivo se muestran como nombres de las prendas en el vestidor.

Las imágenes actuales del README son una referencia de diseño. No se han inventado prendas ni se han convertido automáticamente en capas: exporta cada elemento real desde el archivo de ilustración.
